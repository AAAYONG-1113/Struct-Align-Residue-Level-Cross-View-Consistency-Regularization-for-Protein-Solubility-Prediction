# Package Contents

This folder is a lightweight GitHub/submission package for the Struct-Align protein solubility manuscript.

Included:
- Core training and evaluation code.
- BIBM manuscript source and compiled PDF.
- Final paper figures in PDF/PNG/SVG where available.
- Machine-readable result tables.
- Lightweight CSV data and split metadata.
- Diagnostic summaries for alignment weight, regularization probes, and structure perturbation tests.

Not included:
- Full PDB structure folders: `pdbs_3000/`, `pdbs_7000/`.
- Full ESMFold/NetSolP structure archives.
- ProtSolM expanded intermediate directories.
- Model checkpoint files (`*.pth`, `*.pt`).
- Figure-generation scripts and manuscript-facing reports.

Large excluded artifacts should be uploaded separately using Git LFS, GitHub Releases, Zenodo, OSF, Figshare, or institutional storage, then linked from `README.md`.
